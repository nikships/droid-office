# Controls

| Key | Action |
| --- | --- |
| W A S D | Walk (hold Shift to run); on the ladder, W and S climb |
| ↑ / ↓ | Smoothly raise / lower eye height, from normal to 3× |
| Space | Jump (you can land on desks, couches and the cars in the garage) |
| Mouse drag / wheel | Orbit / zoom the camera |
| E | Interact: hire a worker, open its terminal, read a board, take an issue's note off the board, prompt a board agent, read the docs at the bookshelf, sit down (or get up), ride the elevator, climb the ladder (or get off it), slide down a fire pole, grab a coffee |
| P | Prompt: give a task to a new worker, or to the one at this desk |
| C | Changes: the files the worker at this desk changed and their diff; commit, discard, open a PR, or Commit & open PR to have the worker do both (a tab per repository when the task spans several). In it, **T** switches between the diff and the worker's terminal |
| B | Open a shell at an empty desk |
| R | Resume a sleeping worker (or restart a shell) |
| X | Send a worker home (frees the desk; a worker with its own worktree asks what to do with it) |
| O | Open a pull request for a worker on its own branch, or see the one it has (a worker across several projects gets one in each) |
| N | Go to the worker that has waited longest on someone; again for the next one |
| Command + 1–9 / 0 | Teleport to the numbered floor (0 is floor 10), keeping your position and view instead of arriving in the elevator. Works from terminals and windows too |
| F | Hang a picture from the web on a wall (scroll to size it, click to hang it) |
| Q | Put back the issue card you're carrying |
| G / 1–6 | Emote: hold G for the wheel (point and let go) or press 1–6 to wave, give a thumbs up, clap, dance, point or facepalm; it plays on your character. With the wand drawn, 1–5 are its spells: Lumos, swish and flick, sparkler, ship it, run the build. With the Magnum drawn they're its tricks: twirl, inspect, cylinder spin, yy, blow the smoke off, flip |
| 7 | Draw the droid wand, or the .44 Magnum if you picked it in ⚙️ Settings → You (or put it away; mash it to cancel one into the other); tap left-click on a worker to open its terminal, hold for 0.75s and release to dismiss it; either opens a laptop screen's UI from any distance |
| / | Search every terminal on your floor |
| Tab | The ☰ menu: every window, and what shows on screen |
| Esc | Close any window and get back to looking around. In a terminal, Esc goes to the program (to back out of a menu or interrupt the agent) |
| Shift + Esc | Leave a terminal (so does Ctrl + ], the ✕, or Esc after clicking off the terminal) |

You can also click a nearby desk to interact with it, or click a worker in the Workers panel (**🤖 Workers**, top right) to open its terminal.
