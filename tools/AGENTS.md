# Tools

Offline asset generators and benchmarks (outside `npm test` and release builds, aside from pure helpers tested in `tests/frame-bench.test.ts`, `tests/thermal-bench.test.ts`, and `tests/orchestration-eval.test.ts`).

- **`tools/props/generate.py`** (`blender --background --python tools/props/generate.py [-- <names>...]`) + `node tools/props/verify.mjs`: builds metre-scale GLBs matching `DESK_SIZE` (`src/shared/layout.ts`, capped by `TRI_BUDGET`) into `src/client/public/props/<name>.glb` and `manifest.json`, leaving unnamed props byte-identical.
- **`node tools/android-terminal.mjs`**: copies `@xterm/xterm`, its CSS, `@xterm/addon-unicode11` and license from `node_modules` into `android/app/src/main/assets/terminal/vendor/` (`tests/android-terminal.test.ts` enforces parity; ignored by Biome). Run after `npm ci` whenever xterm changes in `package-lock.json` and commit the output.
- **`node tools/android-richblock.mjs`**: copies Mermaid's single-file build, KaTeX's script, stylesheet and woff2 fonts, and their licenses from `node_modules` into `android/app/src/main/assets/richblock/vendor/` (`tests/android-richblock.test.ts` enforces parity; ignored by Biome and Oxlint). Run after `npm ci` whenever Mermaid or KaTeX changes in `package-lock.json` and commit the output.
- **`node --import tsx tools/android-model-icons.mjs`**: renders pinned LobeHub SVGs via sandboxed offline Whiteboard Chromium into 128px transparent PNGs and a hash manifest for Android (`tests/model-brand.test.ts` checks hashes, dimensions and monochrome exceptions). Run after changing `MODEL_BRANDS` or bundled SVGs and commit the output.
- **`node --import tsx tools/thread-fixture.mjs`**: updates `expected` and `paging` in `android/app/src/test/resources/thread-presentation-golden.json` from `presentThread` (`src/shared/thread-presentation.ts`), preserving captured `entries` (`tests/thread-golden.test.ts` and Android JUnit enforce parity). Run after changing Thread grouping or wording, review the diff, and commit.
- **`uv run --with pillow python tools/tray-icon.py`**: renders `build/icon.png` into `src/desktop/tray-icon.ts` (18pt @1x/@2x, orange active and dim orange stopped, non-template so it stays distinct from DroidProxy's monochrome glyph). Run after changing `build/icon.png` and commit.
- **`tools/terminal-symbols.py`**: rebuilds `src/client/public/fonts/` icon woff2 from the pinned Nerd Fonts subset (using header-pinned `fonttools` and `brotli`). Read [docs/terminal-glyphs.md](../docs/terminal-glyphs.md) before changing advance width or outlines.
- **`tools/frame-bench/`**: frame-pacing, input-to-display latency (`bench.mjs`, `latency.mjs`, `matrix.sh`, `display-trace/`) and counterbalanced ABBA sensor thermals (`thermal.mjs`) on a clone with `--user-data-dir` (`launch.mjs` refuses the installed app, owner `userData` and `:4600`). Read [frame-bench/README.md](frame-bench/README.md) and load the `office-thermals` or `performance-proof` skill before measuring: acquire the display lock on shared machines, keep sensor windows free of heavy load, record background load, and keep raw clone/profile/sensor artifacts uncommitted.
- **`tools/scene-hash.mjs`**: hashes `SCENE_INPUTS` into `__SCENE_HASH__` (`vite.config.ts`) to invalidate saved bounce-light bakes when scene inputs change (`tests/scene-hash.test.ts` verifies every path exists).
- **`node --import tsx tools/backtest-wake-filter.mjs [--dry]`**: replays real `droid_office` team traffic (direct and Script-embedded `team_report`, `team_note`, `lead_notify`, `visit_message` calls in `~/.factory/sessions`, plus `done` events from floor `team.json` files) and labeled chatter cases through the live inter-agent noise gate (`src/server/wake-filter.ts`) with the installed office's `gemini.json` key (`--key-file`, `--team`, `--sessions`, `--limit` and `--out` override the defaults); `--dry` builds requests without calling Gemini. Writes `summary.json` and the per-message `audit.json` to `$TMPDIR/wake-filter-backtest/`; keep both uncommitted since they quote personal transcripts. Run after changing guardrails, thresholds or prompts and check that no substantive message is blocked.
- **`tools/orchestration-eval/`**: repeatable multi-role orchestration and Office MCP eval harness (`bun tools/orchestration-eval/run.ts`; see [orchestration-eval/README.md](orchestration-eval/README.md)) measuring context footprint and active-lead rubrics across `orchestrator`, `external-bot`, `floor-lead`, and `subagent` against live `prompts.ts` and `src/server/office-mcp/`. Keep `runs/` uncommitted.
