# Client

- Vite root configured by the repository root's `vite.config.ts` (register every shipped HTML entry in `build.rollupOptions.input`; static files in `public/` serve from `/`). Typechecked by `tsconfig.client.json` (Bundler resolution, DOM, no Node types, extensionless relative imports including `../shared/*`), using the root `package.json`.
- DOM modals and panels live in `ui/` and the three.js scene lives in `world/` (each has its own `AGENTS.md`); `/dashboard` (`dashboard*.ts`) is the web companion.
- Keep modules imported by `tests/` (such as `player.ts`, `world/office.ts`, `world/gun.ts`) free of `window`, `document` and WebGL calls at import time so `node --import tsx` loads them cleanly.
- Send and receive `ClientMsg` and `ServerMsg` (`src/shared/protocol.ts`) through `net.ts`, updating server handlers and client readers together.
- Verify interactive changes through `window.office` (`automation.ts`; see the `office-3d-testing` skill and [docs/guide/development.md](../../docs/guide/development.md#automation-api-windowoffice)). New ☰ menu items and interactables appear automatically; wire new movement modes through `AutomationHost` in `main.ts`.
- Source hot reload (Settings → Office & floors, or Vite on `:5173`) reloads the full page rather than hot-swapping three.js modules or restarting the server ([docs/guide/development.md](../../docs/guide/development.md#source-hot-reload-with-the-normal-local-launch)).
- `shader-warmup.ts` precompiles shaders during loading for reachable `(scene, target, pointLights, probeGrids, handToneMap)` pairings only (probe grids run only on Remastered's float target; warming unreachable pairings adds seconds of blocking links). Register any material introduced after initial load (spells, muzzle flashes, beams, book pages, smoke, swapped props) in `shader-warmup.ts` in the same change so first draw never stalls mid-session.
- Saved bounce-light bakes key on `SCENE_HASH` (`scene-hash.ts`, from `SCENE_INPUTS` in `tools/scene-hash.mjs`). Add new scene-feeding paths to `SCENE_INPUTS`, or bump `BAKE_FORMAT` in `remaster-settings.ts` when probe-visible lighting changes outside `SCENE_INPUTS` (such as base light colors in `main.ts` or external shader chunks).
