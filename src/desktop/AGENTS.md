# Desktop

Electron main process for the Mac app (`tsconfig.desktop.json` → `dist/desktop/main.js`, `.js` relative imports; sandboxed preloads use `.cts` → `.cjs`). Office UI lives in `src/client`, loaded with `sandbox: true` and `contextIsolation: true`.

- **Presenter, offscreen input, `page/shim.ts`, CDP focus/visibility, crash or paint-stall recovery, presenter timers**: read [presenter.md](presenter.md).
- **Finder integration (`finder.ts`, `finder-links.ts`, `native/mac/`, Keychain bridge)**: read [docs/finder.md](../../docs/finder.md).
- **User data & isolated runs**: `userData` is `…/com.nikships.droid-office` (the bare `Droid Office` folder belongs to the older Unity app). Pass `--user-data-dir=<folder>` and `--startup-check` when testing a packaged app so the installed app's lock, settings and logs stay untouched.
- **Daemon & Chromium**: `office.ts` spawns `bin/droid-office.js` on Electron's Helper binary (`runtime.ts`, `ELECTRON_RUN_AS_NODE=1`) in the login shell environment (`shell-path.ts`). Quitting sends `SIGTERM` so workers and the PTY host survive restarts; **Quit and Stop Workers…** sends `SIGINT`. `browser.ts` runs non-fatal `droid-office browser install` on the Helper binary at launch into the shared folder named by `src/server/whiteboard-browser.ts`.
- **Menu bar vs quit**: Closing the window (Cmd+Q / **Close to Menu Bar** included) hides the Dock icon and keeps the daemon running behind `tray.ts` (`tray-model.ts`, `tests/desktop-tray.test.ts`; regenerate `tray-icon.ts` with `tools/tray-icon.py`), with `windowWanted` keeping restarts or crashes from reopening it. Stop the office only in `before-quit` (Quit menu items, Option+Cmd+Q, Dock Quit, logout, shutdown, updates).
- **Single-window mode switch**: The app owns at most one window in `settings.mode`: `office` (presenter) or `companion` (`/dashboard` in `companion.ts`), mapped solely by `officePage()` and toggled via `switchMode` (`main.ts`, `switchLabel` in `tray-model.ts`). Detach (`win = undefined`), exit full screen (`leaveFullScreen` in `full-screen.ts`, `tests/desktop-full-screen.test.ts`), and close the old window before opening the new one so macOS never strands a black full-screen Space.
- **Startup gates**: Fail loud, never degraded. `requirements.ts` (`tests/startup-requirements.test.ts`) enforces macOS 14+ (`MIN_MACOS` / `MIN_DARWIN`, kept in sync with `mac.minimumSystemVersion` in `electron-builder.yml`) and Apple silicon Pro/Max/Ultra (`DROID_OFFICE_ALLOW_ANY_CHIP=1` is for CI base-chip VMs only; local base-chip runs must report the gate). Route native module and shared-texture errors through `failStartup(...)` (`startup.ts`, `startup-failure.ts`).
- **Updates & packaging**: `updates.ts` installs Squirrel.Mac zips from `latest-mac.yml` signed by the same Developer ID inside the single `update-window.ts` sheet (new states are phases in `update-view.ts`, `tests/desktop.test.ts`). `electron-builder.yml` packs arm64 hardened-runtime bundles (`asar: false`, `npmRebuild: false`, `build/`). `npm run build:native` (`native/build.mjs`) builds both `native/presenter/build/Release/presenter.node` (`native.ts`) and the Swift Finder bundles in `native/mac/build/` (signed before outer sealing by `build/signFinder.mjs`). Declare and sign any new runtime native artifact in `electron-builder.yml` and verify it in `release.yml`.
- **Untrusted page boundary**: Treat the loaded page as untrusted; keep `electron` and the native addon out of its reach, and validate every page value before it touches files, shells, URLs or native code. Accept page-to-host messages exclusively through the `__droidOfficeHost` CDP binding (`input-bridge.ts`: fixed allowlist `lock`, `exit`, `escUp`, `editable`, ≤512 bytes, `trustedContext` main frame at the office origin); add any new message to the allowlist, parser tests and guide together.
